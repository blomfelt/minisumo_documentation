# CRF minisumo++2027 (CRFminisumoplusplus2027)

after 2026 robotsm we sold out of kits that were arduino based and ran out of batteries that were cheap, pcbs and needed to make some pretty big changes on the models anyway... so why not make upgrades!?

## concept
a minisumo .. plus some other things .. plus even some more!
1. minisumo for robotsm primarily but as possible a module that can be a spring board into other things
 - minisumo that one steers like an rc car via bluetooth!
 - lego version! .. encapsulate motors and such into a robot combat like (or autonomous robot?) that can be lego'd together!
 - death racers [ eg ](https://www.youtube.com/watch?v=i10rxmsKHts)
 - robot combat base module
 - more? why not?? probably possible
    - line following!?
    - esphome controlled robot w/ or w/o home assistant!?

## main features
1. good for beginners to meet primary goal of minisumo for robotsm
2. cheap as chips
3. possible to make really really smallish for example to encapsulate into lego!
4. more voltage to motors!
5. battery charging possible!
6. possibility to expand and reuse gpio's or other purpose robots!
